# 01 — About This Repository

This repository is the public, English-only record of a structured cybersecurity study plan I ran in
November 2026. It exists for one reason: to let a recruiter, hiring manager or SOC lead judge my work in a
few minutes without reading 200 pages of notes.

## What it answers

| Question | Where the answer lives |

## Scope of the sprint

Two TryHackMe learning paths (Pre-Security and SOC Level 1), six technical write-ups, two certificates, one
home SOC lab, and a small set of Python utilities written to automate the documentation work.

## How to read this in five minutes

1. **[Skills](../03-skills/README.md)** — one table, one row per skill, each linked to the work that proves it.
2. **[Practical Evidence](../06-practical-evidence/README.md)** — the six investigations, summarised as
   scope → method → finding → outcome.
3. **[Lessons Learned](../08-lessons-learned/README.md)** — what changed in how I work, written in plain
   language.

If you only have two minutes: the skills table and the evidence index are the whole portfolio in two
screens.

## What this repository is not

- It is **not** a walkthrough dump. There are no flags and no room answers from rooms that are still active.
- It is **not** a certificate wall. The certificates page links to the platform profile; the value is the
  evidence behind them.
- It is **not** finished. The next-steps section is part of the point.

## Scope limits

The write-ups describe lab environments, not production systems. Where a lab could not be completed, or a
value came from a published walkthrough rather than my own observation, the write-up says so. A portfolio
that overstates its evidence is worse than a smaller honest one.
