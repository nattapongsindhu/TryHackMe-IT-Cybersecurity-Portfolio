# Study Notes

Concept summaries written in my own words, one file per topic. These are **explanations, not
walkthroughs** — no flags, no room answers, and no step-by-step solutions for rooms that are still
active on TryHackMe.

The test I applied to every note: could I explain this to an interviewer without notes in front of me,
and could I apply it to a ticket I have never seen?

## How these notes were written

Each note started as a page of half-sentences during the module, then was rewritten after the
associated investigation, when I could see which parts actually mattered. Where a note is still thin,
it is because I have not yet used that concept on a real case — that is stated in the note rather than
padded out.
